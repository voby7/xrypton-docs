XRYPTON is an all-in-one Discord bot built to handle everything your server needs, from hardened security and moderation tools to economy systems, AI interactions, and entertainment. Instead of juggling a half-dozen bots with overlapping permissions, you get one cohesive platform where every module is designed to work together. Whether you run a small community or a large public server, XRYPTON scales with you and gives your staff the controls they need to keep things running smoothly.

## Feature Categories

XRYPTON organises its functionality into focused modules, each handling a distinct area of server management or member engagement. Here is a quick overview of what each category brings to your community.

## How Commands Work

Every XRYPTON feature is available as both a **slash command** and a **prefix command**, so your members can use whichever style they prefer. The default prefix is `,` (comma) and you can change it per server at any time. Run `/help` or `,help` to explore commands inside Discord, or browse the full command reference at [xrypton.vercel.app](https://xrypton.vercel.app).

<Note>
  XRYPTON enforces a rate limit of **3 commands per 5 seconds per user** and **4 commands per 5 seconds per channel** to keep performance consistent for everyone.
</Note>
