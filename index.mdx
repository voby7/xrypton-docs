## Getting Started

<Steps>
  <Step title="Invite XRYPTON">
    Use the `/invite` command inside any server where XRYPTON is already present, or visit [xrypton.vercel.app](https://xrypton.vercel.app) to get the invite link. Grant the **Administrator** permission for full functionality.
  </Step>
  <Step title="Set Your Prefix">
    The default prefix is `,`. Use `/prefix add <prefix>` to change it to something custom for your server, or continue using slash commands — all core features are available as `/` commands.
  </Step>
  <Step title="Enable Security">
    Run `/antinuke enable` and `/antiraid massjoin enable` to protect your server right away. See the [Security](/security/antinuke) section for detailed configuration.
  </Step>
  <Step title="Explore Features">
    Browse the docs to set up the features your community needs — leveling, economy, tickets, giveaways, and more.
  </Step>
</Steps>

<Note>
  XRYPTON requires **privileged intents** (message content, guild members, presences) to be fully functional. Make sure these are enabled when you invite the bot.
</Note>
